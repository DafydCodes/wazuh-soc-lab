# Wazuh SOC Lab – 7 Days Hands-on Project

## About the Project
This repository documents my 7-day journey of building a Security Operations Center (SOC) lab using Wazuh, an open-source security monitoring platform.

The project focuses on understanding SIEM, endpoint monitoring, security event analysis, threat detection, and incident response through practical implementation.

## Objectives
- Deploy and configure Wazuh.
- Integrate endpoints using Wazuh agents.
- Monitor endpoint activities.
- Analyze security events and alerts.
- Implement File Integrity Monitoring.
- Explore threat detection and incident response.
